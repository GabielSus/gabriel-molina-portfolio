# Gabriel Molina — Portfolio

Portafolio profesional construido con Next.js, TypeScript y CSS responsive.

## Desarrollo

```powershell
npm install
npm run dev
```

Abrir `http://localhost:3000`.

## Producción

```powershell
npm run build
npm start
```

El proyecto está preparado para desplegarse en Vercel.

## Contenido

- Guatemala Export Analytics — demo pública en Vercel y case study de datos/forecasting.
- Inmetagro 360 — demo pública y case study Full Stack.
- MF360 — case study local-first con capturas reales del producto, arquitectura multimedia y decisiones técnicas.
